# 🚇 Metro Rush - Corrida Infinita

> Jogo estilo Subway Surfers feito com HTML5 Canvas + JS puro. PWA 100% offline.

### **🎮 Jogar Agora**
**https://SEUUSER.github.io/NOME-DO-REPO/**

Adicione à tela inicial no celular pra jogar como app.

### **📱 Como Jogar**
| Ação | Mobile | PC |
| --- | --- | --- |
| Mover Esquerda | Deslizar ← | Seta ← |
| Mover Direita | Deslizar → | Seta → |
| Pular | Toque na tela | Seta ↑ / Espaço |

**Objetivo**: Pegue moedas ★ e desvie dos trens. Sobreviva o máximo possível.

### **✨ Features**
- **PWA**: Instala no celular e roda offline
- **Mobile First**: Swipe otimizado pra celular  
- **Sem dependências**: Vanilla JS puro
- **Dificuldade progressiva**: Fica mais rápido com o tempo

### **🛠️ Stack**
HTML5 Canvas + JavaScript + CSS3 + PWA

### **📂 Deploy GitHub Pages**
1. Suba todos os arquivos no repo
2. Settings > Pages > Deploy from branch > `main` > `/root` > Save
3. Acesse: `https://SEUUSER.github.io/NOME-DO-REPO/`
